# 业余无线电模拟训练

业余无线电台 **A / B / C 类**操作技术能力验证的在线模拟训练网页。打开即用，无需安装、无需联网、没有后端。

## 在线使用

部署好之后访问：`https://<你的用户名>.github.io/<仓库名>/`

## 功能

* **A / B / C 三类**分开训练，题量与时长按官方标准
  | 类别 | 试卷 | 时长 | 合格线 |
  | --- | --- | --- | --- |
  | A 类 | 40 题（单选 32 · 多选 8） | 40 分钟 | 30 题 |
  | B 类 | 60 题（单选 45 · 多选 15） | 60 分钟 | 45 题 |
  | C 类 | 90 题（单选 70 · 多选 20） | 90 分钟 | 70 题 |
* 每类另有**快速练习**与**多选强化**两档，也可自定义题量与时长
* 每次开考**随机抽题**，每题**选项顺序随机打乱**
* **倒计时**，归零自动交卷；剩余 10 分钟变黄、5 分钟变红
* 考试过程中不显示任何对错提示，**交卷后统一公布成绩与逐题解析**
* 交卷后可只看错题 / 只看未答 / 只看多选，并按知识板块统计正确率
* 答题进度自动存在本机浏览器，误刷新可继续作答
* 界面自适应全屏，手机、平板、电脑都能用

## 题库

* 共 **1322 道**唯一题目（A 类 682、B 类 1119、C 类 1229），依据
  《业余无线电台操作技术能力验证题库（2025 年版）》整理
* **每道题都有解析**，共 1322 篇，说明判断依据、正确选项为何成立、干扰项错在哪，
  计算题给出公式与代入过程
* 题目依赖插图而原文件未提供图片的（A 类 1 题、B 类 24 题、C 类 53 题）已剔除

## 仓库结构

```
index.html    模拟训练主程序（题库与解析全部内嵌，单文件）
404.html      访问不存在路径时的页面
.nojekyll     跳过 GitHub Pages 的 Jekyll 处理
```

## 部署到 GitHub Pages

1. 把本仓库推送到 GitHub（公开仓库才能免费使用 Pages）
2. 仓库 **Settings → Pages → Source** 选 `Deploy from a branch`
3. 分支选 `main`，目录选 `/ (root)`，保存
4. 等 1～2 分钟，访问 `https://<用户名>.github.io/<仓库名>/`

## 说明

* 纯静态页面，题目与答案都在 `index.html` 里，**打开源码即可看到答案**，
  适合自学与练习，不适合用作正式考核。
* 答题记录只存在访问者自己的浏览器（localStorage），不会上传到任何服务器。
* 题库与解析根据公开的官方题库整理，仅供备考练习使用。
